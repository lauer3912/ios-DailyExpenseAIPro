# DailyExpenseAIPro — Personal Finance Tracker

## Project Overview
DailyExpenseAIPro is a professional personal finance management app designed for the global market.

**Core Features**:
- Income & expense tracking
- Budget management & reminders
- Savings goals
- Reports & analytics
- Widget support
- AI-powered insights

**Tech Stack**:
- SwiftUI + MVVM
- iOS 17.0+
- UserDefaults (local persistence)
- WidgetKit
- Swift Charts# Trigger
