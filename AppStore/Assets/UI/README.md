# AppStore UI Assets

This directory contains UI mockups and design reference images for Daily Expense AI Pro.

## Files

| File | Description | Size |
|------|-------------|------|
| `UI-Mockup-v1.png` | Initial UI mockup design | Various |

## Purpose

These mockups are used for:
- Human review of UI design direction
- Reference for implementing SwiftUI views
- Documentation of design decisions

## Design Guidelines

- **Style:** Modern, clean, Glassmorphism inspired
- **Primary Color:** #10B981 (Emerald Green)
- **Background:** Light gray #F5F5F7 (light mode), Dark #1C1C1E (dark mode)
- **Accent:** #34D399 (Mint)
- **Typography:** SF Pro, system font

## Notes

UI mockups should be reviewed and approved by human before implementation begins (per SOP Stage 0.2).
